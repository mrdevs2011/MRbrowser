MRBrowser

Yonma-yon tablar, Brave uslubidagi shields, ko'p akkauntli profillar.

1. Tez o'rnatish (Linux / macOS)

Terminalga nusxalab tashlang:

curl -fsSL https://raw.githubusercontent.com/mrdevs2011/MRbrowser/main/install.sh | bash

Tugagach ishga tushiring:

mrbrowser

2. Qo'lda (manba koddan)

Kerak: git, Node.js + npm, Electron (Arch: sudo pacman -S electron).

git clone https://github.com/mrdevs2011/MRbrowser.git
cd MRbrowser
npm install
npm start

3. AppImage yig'ish (Linux)

cd MRbrowser
npm run dist
./dist/MRBrowser.AppImage

4. Kirish (login)

  1. MRBrowser'ni oching.
  2. Kirish oynasida Kirish tugmasini bosing (akkaunt yo'q bo'lsa - ro'yxatdan o'ting).
  3. Akkauntingiz bilan kiring - sozlamalar bulutga avtomatik sinxronlanadi.

Yangilash

1-bo'limdagi buyruqni qayta ishga tushiring.
